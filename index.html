Read the evidence

The baseline is deliberately limited.

Thirty synthetic evaluation cases produce 25 exact matches. Three requests that should require review receive a route proposal. That is a concrete reason to keep this baseline out of production.

Run npm run evaluate for the full report, including negation, paraphrase and sensitive-context failures.

Engineering scope

Proposals never dispatch work.

The demo validates input, proposes one of three categories or abstains, and returns a reason. A separate model-output contract tests schema, quoted evidence and agreement with the baseline. It does not call an AI model.
