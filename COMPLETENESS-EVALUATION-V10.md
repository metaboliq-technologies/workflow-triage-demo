# Decisive evidence completeness, paired evaluation v10

Hold v9 routing semantics, one exact 4–120 UTF-16-unit source quote, JSON schema,
validator, rules and bounded-v8 transport constant. Append an evidence-selection
instruction through explicit createCompletenessAdapter. Historical adapters stay
byte-for-byte unchanged. Prompt changes can still affect routing; measure both.

## Predeclared design

- Freeze implementation before implementer case exposure.20 fresh fictional cases,
  four each security_context, sensitive_scope, multi_intent_scope, ordinary_evidence,
  protective_scope. Shuffle before IDs; check exact non-reuse against nine older sets.
- Separate AI author and initially blind AI label/criteria reviewer. Reviewer sees
  only requests/policy before saving initial decisions and minimum evidence facts,
  not assigned groups or author labels. Retain all originals, routing disagreements
  and every case's criteria reconciliation. Unresolved labels block calls. All cases
  target single-span feasibility assessed by AI, not proof about every valid quote.
- Compare previous sensitive-context-v9 versus updated evidence-completeness-v10 on
  each case. Alternate arm order by shuffled case position. Gemini3.5FlashLite;
  quoted-v1;15-second spacing between classifications.20 cases x2 arms x at most2
  attempts =80 maximum attempts.30s attempt/65s classification limits unchanged.
- Stop entire batch on429/auth/configuration, unhandled Retry-After advice or three
  consecutive unrecovered transient classifications. Do not rerun wrong routes or
  invalid quotes. Failed/unattempted outputs get no routing/evidence credit.
- Report first/final views, all20 per-arm denominators, unchanged rules, derived
  guarded views, common-valid pairs, every failure/mismatch, review and proposal
  coverage, all-attempt usage and latency. No extra calls for guards.
- After calls, separately shuffle/blind valid output items. A fresh AI output reviewer
  sees input, frozen reference and evidence criteria, returned category/quote. It must
  not see arm, call order, latency, run metadata, aggregate scores or map to arms until
  grades are sealed. Keep initial grades; flag label/criteria ambiguity without tuning.
- Grade semantic support for returned policy decision and coverage of frozen reference
  minimum facts independently. A wrong route may quote a correct trigger. Report a
  joint route+support+coverage success measure and both component measures. Invalid or
  missing outputs are zeros in all-case denominators, not omitted. Exact source validity
  is checked mechanically; semantic judgments are AI review, not human adjudication.
- Evidence example quotes are feasibility examples, not answer whitelists; judges use
  semantic minimum facts. No repair, favorable relabelling or post-result prompt tuning.

## Limits

Small policy-directed fictional English set, AI-assessed feasible single quotes,
correlated author/reviewer blind spots and one model run do not establish customer
performance, robust evidence completeness, stable availability or production readiness.
Discontiguous/longer evidence is outside this one-quote study. Blinding does not make
AI judgments ground truth. Routing and evidence metrics can differ. Temporal provider
variation, longer prompts and generation remain confounds. A paired observation is
not proof of a general causal mechanism. The set becomes seen after assembly.

Checkpointing is per classification, not attempt; unknown interrupted calls cannot
be assumed zero or safely rerun. Missing usage is unknown, not zero. Keep every failed
attempt, including retries that later recover. No business actions, billing changes,
new projects/credentials or quota workarounds. Manual workflow only; no automatic runs.
